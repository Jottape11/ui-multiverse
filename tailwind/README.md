# Atividade Tailwind CSS — SE Palmeiras ⚽🟢

Projeto desenvolvido para a disciplina de **Front-End Design** da FIAP (Engenharia de Software - 2º Semestre).

O objetivo é explorar o paradigma **utility-first** utilizando **Tailwind CSS v4** diretamente no HTML, aplicando layouts responsivos, CSS Grid nativo, Flexbox, componentes com botões interativos, filtros visuais e animações.

## 🚀 Principais Seções Implementadas

- **Navbar:** Menu responsivo com alinhamento flexível, logo com ícone e botão de ação Avanti.
- **Hero Banner:** Cabeçalho com tipografia esportiva (Montserrat), slogan histórico e foto de destaque do estádio.
- **Hegemonia (CSS Grid):** Painel de títulos em 3 colunas e linha inferior mesclando colunas (`col-span-2` e `col-span-1`).
- **Experiências (Cards & Botões):** Cards de serviços explorando alinhamento vertical e variantes de botão (*sólido* e *outline*).
- **Galeria (Filtros no Hover):** Fotos demonstrando filtros nativos (`blur-xs` e `grayscale`) com transições suaves (`transition duration-500`).
- **Filosofia & Animações:** Citação de Abel Ferreira com avatar circular, troféu saltando (`animate-bounce`) e coração verde pulsando (`animate-ping`).
- **Footer Institucional:** Rodapé em 3 colunas com dados de contato, redes sociais e direitos autorais.

---

## 🛠️ Tecnologias
- **HTML5:** Estrutura semântica.
- **Tailwind CSS v4 (Browser CDN):** Estilização utilitária sem CSS externo.
- **Boxicons (v2.1.4):** Ícones vetoriais.
- **Google Fonts (Montserrat):** Tipografia oficial.
