# Atividade Tailwind CSS 🎨

Projeto desenvolvido para a disciplina de **Front-End** da FIAP (Engenharia de Software - 2º Semestre).

O objetivo principal desta atividade é praticar a estruturação e estilização de páginas web modernas utilizando o framework de utilitários **Tailwind CSS**, explorando layouts responsivos, grid, flexbox, componentes e animações diretamente no HTML.

---

## 🚀 Funcionalidades e Estrutura

- **Navegação (Navbar):**
  - Barra de navegação responsiva com layout flexível (`flex items-center justify-between`) e links com estados hover (`hover:text-cyan-600`).
- **Header:**
  - Cabeçalho introdutório centralizado com tipografia e cores aplicadas via classes utilitárias.
- **Grid Layout:**
  - Demonstração do CSS Grid utilitário do Tailwind (`grid`, `grid-cols-3`, `col-span-*`, `gap-*`).
- **Componentes & Cards:**
  - Seção com cards estruturados (`p-5`, `bg-white`) e botões com variantes de estilo.
- **Galeria de Imagens e Filtros:**
  - Exibição de imagens com classes utilitárias de efeitos visuais (`blur-xs`, `grayscale`) e transições suaves (`transition duration-500 ease-in-out`).
- **Animações Utilitárias:**
  - Demonstração de animações nativas do Tailwind (`animate-ping`, `animate-bounce`, `animate-spin`) combinadas com ícones da biblioteca Boxicons.
- **Footer:**
  - Rodapé simples com estilo utilitário e indicação do projeto.

---

## 🛠️ Tecnologias e Documentação

- **HTML5:** Estruturação semântica.
- **Tailwind CSS (via CDN / Browser Runtime):** Framework CSS utility-first para estilização rápida e modular.
- **Boxicons:** Biblioteca de ícones vetoriais via CDN.
- **Documentação Oficial:**
  - [Tailwind CSS - Site Oficial](https://tailwindcss.com/)
  - [Tailwind CSS - Documentação e Conceitos](https://tailwindcss.com/docs)

## 💻 Como Executar

Por se tratar de uma aplicação puramente estática em HTML e Tailwind CSS via CDN, não é necessária a instalação de dependências:

1. Clone o repositório:
   ```bash
   git clone https://github.com/Jottape11/tailwind.git
   ```
2. Abra o arquivo `index.html` em qualquer navegador web (ou utilize a extensão *Live Server* do VS Code).
