# Game Center - Atividade Bootstrap 🎮

Projeto desenvolvido para a disciplina de **Front-End** da FIAP (Engenharia de Software - 2º Semestre).

O objetivo principal desta atividade é praticar a estruturação de páginas web responsivas utilizando os principais componentes do framework **Bootstrap 5**, baseando-se em uma proposta de layout comercial.

---

## 🚀 Funcionalidades e Estrutura

- **Navegação & Modal:**
  - Header com barra de navegação e botões de atalho.
  - Botão *"Buy Now"* que aciona um modal do Bootstrap para seleção rápida de produtos e direcionamento para o carrinho.
- **Hero Carousel:**
  - Carrossel dinâmico com banners dos principais destaques (PlayStation 5, GTA VI e EAFC 27).
- **Customer Reviews:**
  - Carrossel interativo (`carousel-dark`) com avaliações de clientes, classificação em estrelas, citação e perfil do usuário.
- **FAQ (Perguntas Frequentes):**
  - Componente *Accordion* com respostas expansíveis sobre garantia, frete e cancelamento de pedidos.
- **Footer:**
  - Rodapé simples com indicação de copyright e créditos didáticos.

- **HTML5:** Estruturação semântica.
- **Bootstrap 5.3 (via CDN):** Componentes estilizados, sistema de grid e utilitários de espaçamento/cores.

## 💻 Como Executar

Por se tratar de uma aplicação puramente estática em HTML e CSS/Bootstrap via CDN, não é necessária a instalação de dependências:

1. Clone o repositório:
   ```bash
   git clone https://github.com/Jottape11/bootstrap.git
   ```
2. Abra o arquivo `index.html` em qualquer navegador web (ou utilize a extensão *Live Server* do VS Code).
