# UI Multiverse 🌌

Repositório prático de Front-End (FIAP - 2º Semestre) comparando três abordagens de desenvolvimento web: **Bootstrap 5**, **Tailwind CSS** e **Vibe Coding**.

---

## 📁 Projetos

```text
ui-multiverse/
├── bootstrap/   # Projeto 1: Game Center (Componentes e Grid)
├── tailwind/    # Projeto 2: SE Palmeiras (Classes Utilitárias)
└── vibecode/    # Projeto 3: Fintech Minimalista (Vibe Coding)
```

---

## 🎮 1. Bootstrap 5 — Game Center

Interface de e-commerce gamer explorando os componentes do Bootstrap 5: Navbar com modal de compra rápida, carrossel de lançamentos, avaliações de clientes e FAQ em accordion.

![Preview - Game Center Bootstrap](assets/screenshots/bootstrap-preview.png)

- **Tecnologias:** HTML5, Bootstrap 5.3, CSS3, Google Fonts.

---

## ⚽ 2. Tailwind CSS — SE Palmeiras

Landing page institucional do Palmeiras estruturada com classes utilitárias do Tailwind CSS v4: sistema de grid nativo para títulos e arena, variantes de botões, galeria com filtros no hover e animações integradas.

![Preview - Tailwind Palmeiras](assets/screenshots/tailwind-preview.png)

- **Tecnologias:** HTML5, Tailwind CSS v4, Boxicons, Google Fonts (Montserrat).

---

## 💳 3. VibeCode — Zenit Finance

Landing page de um banco digital minimalista desenvolvida sob a metodologia de **Vibe Coding**. O projeto explora estética dark mode refinada, smartphone funcional desenhado em CSS, cartão virtual com efeito 3D interativo, comparativo de rendimentos e registro completo de prompts e decisões de design.

![Preview - Zenit Finance VibeCode](assets/screenshots/vibecode-preview.png)

- **Tecnologias:** HTML5, CSS3 Puro, Google Fonts (Hanken Grotesk), GSAP 3.13.0, ScrollTrigger, Lenis 1.3.4.
- **Diário de Bordo:** [`vibecode/processo-vibecode.md`](vibecode/processo-vibecode.md)

---

## 💻 Como Rodar

Abra o arquivo `index.html` de qualquer uma das pastas diretamente no navegador ou utilize a extensão **Live Server** do VS Code.
